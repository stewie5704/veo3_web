# Landing (marketing site)

This folder is the static export for https://aiautocut.com (or root marketing).

- Generated by: `cd frontend && $env:BUILD_LANDING=1; npm run build:landing`
- Source: React componentized `frontend/src/pages/Landing.tsx` + `Landing.css`
- Entry during build: `frontend/landing.html` + `frontend/src/landing/main.tsx`
- Output: `index.html` + `assets/*.js` + `assets/*.css`
- Samples videos are preserved in `samples/` (real mp4s for <video>)

Do NOT edit index.html / assets manually.
Run the Vite build from frontend to update.

Deploy script (deploy.ps1) calls the landing build automatically before git push.
Legacy: old `build.js` + `style.css` kept for reference/rollback only.
